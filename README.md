# Stash extension website

A lightweight website for Stash, a free Chrome extension for saving YouTube videos into custom lists.

## What's included
- Actual screenshots of the extension
- Responsive, accessible landing page with subtle scroll animations
- Interactive screenshots and three-step overview
- Privacy policy at `/privacy.html`

## Enable GitHub Pages
In Settings → Pages, choose **Deploy from a branch**, select **main** and **/(root)**, and save. The expected address is https://shloksheth.github.io/stash-extension-website/.

After the Chrome Web Store listing is published, set `chromeStoreUrl` in `script.js` to the final listing URL.
